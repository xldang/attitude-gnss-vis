算法链与约定 ?

展开完整链路
卫星 ECEF（开普勒 / 笛卡尔传播，含光行时 τ=ρ/c 与地球自转 Sagnac 改正） → 载体 LLH 转 ECEF → 差矢量转本地 ENU → 姿态方向余弦阵 C_enu^b = Ry(−roll)·Rx(−pitch)·Rz(−yaw) → 机体系 LOS → 天线面高度角 E=asin(Z_b/ρ) 过滤 → G=(HᵀH)⁻¹（增广高斯-约当 + 部分主元），未知量顺序 [钟差, x, y, z]，故位置块取**右下** 3×3 → Cov_enu = Kᵀ·Cov_body·K 转到当地 ENU → PDOP = √(σ_E² + σ_N² + 2σ_EN)。
两处容易错的地方：① 对角元不能含钟差（那是 GDOP 的第一项）， 含钟差又漏 z 分量的写法既不是 PDOP 也不是 GDOP；② 位置块在**机体系** 解出来，PDOP 却按定义是**当地 ENU 水平**的量，必须先转过去 —— 直接取机体系 x/y 等于假设天线面板始终水平，姿态一大就整体偏掉。
掩角为“相对于天线面板面”的高度角；Yaw 以正北为 0°、北偏西为正； Height 直接作为椭球高使用（生成脚本写的是平均海平面，偏差 <10 m，对 PDOP 无影响）。 可视星 < 4 时 PDOP 输出 NaN（曲线断开）。
